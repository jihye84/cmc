# 클래식 만년달력 · 하루 한 곡

1년 366일(2월 29일 포함), 하루 한 곡씩 기악 명곡을 소개하는 일력 웹앱입니다.

- 오늘 날짜의 곡이 바로 열리고, 어제·내일로 넘기거나 원하는 날짜로 이동할 수 있어요.
- 날마다 곡에 어울리는 그림이 그려지고, 바탕체 소개글이 함께 나와요.
- **듣기**를 누르면 그날의 추천 연주 영상(2개)이 재생되고, 안 되면 다음 영상 → 음악 서비스 검색으로 넘어가요.
- 탁상 디스플레이·스마트폰 잠금화면용 배경화면 모드와 이미지 저장을 지원해요.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 본체 (이 파일 하나로 동작) |
| `src/data.txt` | 날짜별 곡 정보 `월-일\|곡명\|작곡가\|편성\|테마\|선정 이유` |
| `src/desc/all.txt` | 날짜별 소개글 |
| `src/yt.txt` | 날짜별 유튜브 영상 ID `월-일\|추천1\|추천2` |
| `src/template.html` | 앱 화면 원본 |
| `src/build.py` | `src/`의 데이터로 `index.html`을 다시 만드는 스크립트 |

곡·소개글·영상을 고친 뒤 `python3 src/build.py`를 실행하면 `index.html`이 새로 만들어집니다.
